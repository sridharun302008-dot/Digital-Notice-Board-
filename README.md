Digital Notice Board System

About

A simple Digital Notice Board System developed using Java Swing. It allows users to add, view, update, and delete notices easily.

Technologies Used

- Java
- Java Swing
- AWT

Features

- Add Notice
- View Notices
- Update Notice
- Delete Notice
- Automatic Notice ID
- Automatic Date

How to Run

1. Download "DigNotBoa.java".
2. Compile using "javac DigNotBoa.java".
3. Run using "java DigNotBoa".
